What is WAF++?

WAF++ (Well-Architected Framework++) is a community-driven, cloud-agnostic framework for sovereign, secure, and sustainable cloud architectures. It turns written guidance into machine-readable, verifiable controls.

📄 Whitepaper foundation

Everything in WAF++ is rooted in the WAF++ Whitepaper v1.0 (January 2026) by Sascha Lewandowski, Artem Lajko, Dr.-Ing. Sebastian Meyer, and Tim Urlaub. The whitepaper is not marketing — it is the original reasoning for why this framework exists and why a vendor-neutral alternative is necessary.

The whitepaper starts with a stark observation: multi-cloud is already reality, but security and sovereignty are not. 69 % of organisations report data breaches caused by security and configuration errors, and 68 % of experts rank misconfiguration as one of the most urgent problems in modern cloud architectures.

69% breaches from config errors
$5M+ avg. non-compliance damage
97% German firms want data sovereignty
49% storage budgets hidden fees

Established Well-Architected Frameworks from AWS, Azure, and GCP are valuable inside their own ecosystems, but they are provider-specific by design. They recommend proprietary services that create vendor lock-in, hide mobility costs such as egress fees, and ignore European regulatory expectations. Migrating a single petabyte of data can incur roughly 54 000 US dollars in egress charges alone.

WAF++ was created to close that gap. The whitepaper proposes seven pillars: Security, Cost, Performance Efficiency, Reliability, Operational Excellence, Sustainability, and Sovereignty. The ecosystem has since extended that foundation with an eighth pillar, Agentic, for safe and observable AI-agent integration.

📜 The big picture

This Architecture Decision Record (ADR-000) is the master onboarding document for the WAF++ ecosystem. It explains the overall architecture, the role of every git repository, how the repositories interact, and the conventions a new team member needs to become productive.

WAF++ combines written framework guidance with a concrete compliance engine called PASS that scans Infrastructure-as-Code (IaC), persists results, and visualises them in a browser dashboard.

🧱 Eight pillars

The framework extends the classic AWS Well-Architected Framework with additional pillars tailored to modern, sovereign, and AI-aware systems.

  • Security — protect data, identities, and workloads.
  • Cost — optimise spend and FinOps practices.
  • Performance Efficiency — right-size and tune resources.
  • Reliability — availability, recovery, and resilience.
  • Operational Excellence — run and observe operations.
  • Sustainability — reduce environmental impact.
  • Sovereign — data residency, control, and independence.
  • Agentic — safe, observable AI agent integration.

⚙️ Machine-readable controls

Each control is defined as a YAML file that the engine can load and evaluate automatically. Controls are checked against:

  • Terraform
  • AWS CDK
  • Pulumi
  • Bicep (planned)

🛠️ The compliance platform

The ecosystem is more than documentation. It is a platform made of:

  • wafpass-core — IaC parser and control evaluator.
  • wafpass-server — REST API + PostgreSQL persistence.
  • wafpass-dashboard — React SPA for visualising posture.
  • wafpass-mcp — bridge for AI assistants.
  • wafpass-action — GitHub Actions wrapper.

🌍 Public surface

The public website waf2p.dev hosts marketing pages, the blog, team information, and the integrated Antora documentation viewer for both the German and English framework editions.
