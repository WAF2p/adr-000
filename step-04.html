High-Level Architecture

The WAF++ ecosystem is organised in layers: public surface, compliance platform, and external supporting tooling. A single JSON contract ties the layers together.

🏛️ Architecture layers

┌─────────────────────────────────────────────────────────────────────────────┐
│                              WAF++ Ecosystem                                │
├─────────────────────────────────────────────────────────────────────────────┤
│  Public surface                                                             │
│   • waf2p.github.io  → Jekyll marketing site + Antora docs (framework)      │
├─────────────────────────────────────────────────────────────────────────────┤
│  Compliance platform                                                          │
│   • pass (wafpass-core) → CLI / library / CI scanner                       │
│   • wafpass-action      → GitHub Actions wrapper                           │
│   • wafpass-server      → FastAPI + PostgreSQL persistence layer             │
│   • wafpass-dashboard   → React SPA visualisation                            │
│   • wafpass-mcp         → MCP bridge for AI assistants                      │
└─────────────────────────────────────────────────────────────────────────────┘

🔗 The central contract

The wafpass-result.json schema is the single source of truth between engine, server, dashboard, PDF reporter, and observability exports.

Everything downstream consumes this contract, so versioning the schema is critical when adding new control result types or metadata.

🌐 Public surface

  • Jekyll marketing site at waf2p.github.io.
  • Blog posts, team pages, events, and conference listings.
  • Integrated Antora docs viewer pulling from framework (main-de) and framework-en (main-en).

🛡️ Compliance platform

The engine runs inside CI or on a developer machine, produces a result, and either:

  • Pushes it to wafpass-server for persistence, or
  • Writes local JSON/PDF reports and observability exports.

The dashboard, MCP bridge, and GitHub Action all communicate through the server API.
